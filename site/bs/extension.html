Dodatak za browser

Firefox

Instalacija u Firefoxu — bez developer moda. Dodatak je potpisala Mozilla i sam se ažurira.

Dodaj u Firefox

  1. Prvo instaliraj program (dodatak radi s njim).
  2. U Firefoxu 140 ili novijem klikni Dodaj u Firefox ispod: otvara se zvanična stranica Firefox Add-ons.
  3. Tamo klikni Add to Firefox (Dodaj u Firefox), pa Add (Dodaj).
  4. Prikvači ikonu Video Download (ikona slagalice → pribadača).

Microsoft Edge

Instalacija u Edge iz zvanične prodavnice Edge Add-ons — bez developer moda. Dodatak se sam ažurira.

Preuzmi za Edge

  1. Prvo instaliraj program (dodatak radi s njim).
  2. Klikni Preuzmi za Edge ispod: otvara se zvanična stranica Edge Add-ons.
  3. Na stranici Edge Add-ons klikni Get (Nabavi), pa Add extension (Dodaj proširenje).
  4. Prikvači ikonu Video Download (ikona slagalice → ikona oka).

Izaberi folder
  1. U programu otvori Pomoć → Preuzimanje iz browsera i klikni Kopiraj putanju foldera.
  2. Klikni Otvori dodatke u Chrome-u (ili otvori chrome://extensions) i uključi Developer mode (gore desno).
  3. Klikni Load unpacked (Učitaj raspakovano), zalijepi putanju (Ctrl+V) u polje za folder i klikni Select Folder. Na kraju prikvači ikonu Video Download (ikona slagalice → pribadača).
Chrome ponekad podsjeti na „Developer mode“; to je očekivano. Ako poslije ažuriranja programa dodatak prestane reagovati, u chrome://extensions klikni Reload kod njega. Firefox i Edge dodatak ažuriraju sami.

Korištenje

  • Pusti video na stranici i klikni ikonu Video Download: Preuzmi video koji se pušta ili Preuzmi kao MP3.
  • Desni klik na link ili video: Preuzmi ovaj link ili …kao MP3.
  • Ako program nije pokrenut, klik ga sam pokreće.
  • Prenos uživo i video zaštićen DRM-om se ne preuzimaju.
Mac (beta): folder je unutar programa. U programu Pomoć → Preuzimanje iz browsera → Kopiraj putanju foldera, pa u prozoru za izbor foldera pritisni ⌘⇧G, zalijepi (⌘V) i Enter.
