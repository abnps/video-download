Download only part of a video (clip)

You don't need a two-hour recording for one five-minute answer. Video Download can save only the part between two times.

Steps

  1. Add the video link with Paste.
  2. Click the format button on that video's row and choose Clip (from–to).
  3. Enter the start and end, for example 2:30-6:10 or 1:02:00-1:05:30, and confirm.
  4. Click Download. Only that part is downloaded.

Good to know

  • The file name includes the start and end time, so several clips of the same video don't overwrite each other.
  • To get the full video again, choose Whole video (remove clip) in the same menu.
