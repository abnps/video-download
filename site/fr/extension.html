Extension pour le navigateur

Firefox

Installation dans Firefox, sans mode développeur. L'extension est signée par Mozilla et se met à jour toute seule.

Ajouter à Firefox

  1. Installez d'abord l'application (l'extension fonctionne avec elle).
  2. Dans Firefox 140 ou plus récent, cliquez sur Ajouter à Firefox ci-dessous : la page officielle de Firefox Add-ons s'ouvre.
  3. Cliquez-y sur Ajouter à Firefox, puis sur Ajouter.
  4. Épinglez l'icône de Video Download (icône de pièce de puzzle → épingler).

Microsoft Edge

Installation dans Edge depuis la boutique officielle Modules complémentaires Edge, sans mode développeur. L'extension se met à jour toute seule.

Obtenir pour Edge

  1. Installez d'abord l'application (l'extension fonctionne avec elle).
  2. Cliquez sur Obtenir pour Edge ci-dessous : la page officielle des modules Edge s'ouvre.
  3. Sur la page des modules Edge, cliquez sur Obtenir, puis sur Ajouter l'extension.
  4. Épinglez l'icône de Video Download (icône puzzle → icône œil).

Sélectionner un dossier
  1. Dans l'application, ouvrez Aide → Télécharger depuis le navigateur et cliquez sur Copier le chemin du dossier.
  2. Cliquez sur Ouvrir les extensions dans Chrome (ou ouvrez chrome://extensions) et activez le Mode développeur (en haut à droite).
  3. Cliquez sur Charger l'extension non empaquetée, collez le chemin (Ctrl+V) dans le champ du dossier et cliquez sur Sélectionner un dossier. Épinglez ensuite l'icône de Video Download (icône puzzle → épingler).
Chrome peut vous rappeler le « Mode développeur » ; c'est normal. Si, après une mise à jour de l'application, l'extension ne réagit plus, cliquez sur Actualiser à côté d'elle dans chrome://extensions. Firefox et Edge mettent l'extension à jour tout seuls.

Utilisation

  • Lancez une vidéo et cliquez sur l'icône de Video Download : Télécharger la vidéo en cours ou Télécharger en MP3.
  • Clic droit sur un lien ou une vidéo : Télécharger ce lien ou …en MP3.
  • Si l'application n'est pas ouverte, le clic la démarre.
  • Les directs et les vidéos protégées par DRM ne sont pas téléchargés.
Mac (bêta) : le dossier se trouve dans l'application. Dans l'application, Aide → Télécharger depuis le navigateur → Copier le chemin du dossier, puis dans le sélecteur de dossier appuyez sur ⌘⇧G, collez (⌘V) et appuyez sur Entrée.
