Download a video with subtitles

Video Download can save subtitles with the video: inside the MP4 and as a separate .srt file that video players load on their own.

Steps

  1. Turn on Downloads → Subtitles with the video.
  2. Add the link with Paste and click Download.
  3. Next to the video you get an .srt file with the same name, and the subtitles are also inside the MP4.

Good to know

  • If a video has no hand-made subtitles, automatic ones are used when the site offers them.
  • If the subtitles can't be downloaded, the video is still saved.
  • Downloads → Thumbnail as file cover saves the video's picture as the file cover.
