How it works

From installing to your first file in under a minute.

Install

Run the installer. It doesn't need an administrator and adds nothing else to your PC.

Add a link

Copy a link, click “Paste”, or download straight from the browser with the extension.

Choose and download

MP4 or MP3, then “Download”. The file waits in the Video Download folder.

Help

The most common questions. If something doesn't work: Help → Save a problem report, then send it to us.

Windows says “Windows protected your PC”. What now?

The app doesn't have a paid digital signature yet. Click “More info” → “Run anyway”. The installer's SHA-256 checksum is listed with every release on GitHub.

A video suddenly won't download.

Websites change often. Help → Update the site reader (yt-dlp), then try again.

Why aren't live streams downloaded?

A live stream has no end, so the download would never finish. Download it after it ends and the recording is published.

What does the app send to the internet?

Only what's needed: the link you download goes to that website, and update checks go to GitHub and PyPI. No accounts, statistics or tracking.
