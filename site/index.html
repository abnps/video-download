Features

Everything you need,
nothing you don't.

A simple window, with everything you expect from a good downloader underneath.

MP4 up to the best quality

Best, 1080p, 720p or 480p. Picture and sound are merged into an MP4 (H.264/AAC when the site offers it) that plays on most devices.

Audio only: MP3 or M4A

For lectures, podcasts and music. A finished MP4 turns into an MP3 with one button.

Copy a link, done

The app notices a copied link and adds it to the queue.

Playlists, several at once

Whole playlists, up to 4 downloads at the same time, automatic retry when the connection drops.

Clips, subtitles, cover art

Just a part of a video, subtitles in the MP4 and the thumbnail as the file's cover.

Light and dark theme

Or same as your system. Progress on the taskbar and a notification at the end.

Works almost everywhere

Windows 10 and 11, macOS (Apple chip), Linux and Android, plus the browser extension for Chrome, Edge and Firefox. Mac, Linux and Android are in beta.

Beta New: Video Download for Mac. For Macs with an Apple chip (M1 or newer) and macOS 13 or later. It works, but only a few people have tried it so far: please report anything that doesn't work.

The Mac version isn't signed by Apple yet, so the first start takes a few extra clicks:

  1. Open the downloaded .dmg and drag Video Download to Applications.
  2. Open the app. macOS says it can't verify it: click Done (not “Move to Trash”).
  3. Open System Settings → Privacy & Security, scroll down, click Open Anyway and enter your Mac password.
  4. Open the app again and confirm Open. This is needed only once.

Download for Android (beta)

The app isn't in Google Play, so the first install takes a few extra taps:

  1. Open the downloaded file (Downloads or the browser's download list).
  2. If Android asks, allow installing apps from your browser: Settings → Allow from this source.
  3. If Auto Blocker blocks the install on a Samsung phone, turn it off only for the install (Settings → Security and privacy) and turn it back on afterwards.
  4. If Google Play Protect warns about an unknown app, tap More details → Install anyway.
  5. Later versions install from the app itself: Settings → Check for updates.

Beta New: Video Download for Linux. For 64-bit PCs (x86_64) with Ubuntu 22.04 or newer, Linux Mint 21+, Debian 12+, Fedora 38+ or similar. It works, but only a few people have tried it so far: please report anything that doesn't work.

One file, nothing to install:

  1. Download the .AppImage file and keep it in a folder of your choice (for example your home folder).
  2. Allow it to run: right-click → Properties → Allow executing file as program, or in a terminal chmod +x VideoDownload-linux-x86_64.AppImage.
  3. Double-click it to start. Updates replace the same file, so you never need to download it again.
  4. If it doesn't start, install FUSE (Ubuntu/Debian: sudo apt install fuse3) or start it with --appimage-extract-and-run.
  5. The browser extension works with Chrome, Edge and Firefox from your distribution or the browser's website; browsers installed as Flatpak can't connect to the app yet.

Help

Questions?

If something doesn't work: in the app use Help → Save a problem report, then report the problem. Reports are public: don't include passwords or personal data.

Questions in your language? Ask the community on Discord.

Join our Discord

A video suddenly won't download.

Websites change often. Help → Update the site reader (yt-dlp), then try again. If it still fails, the app offers the nightly yt-dlp with the newest fixes.

Why aren't live streams downloaded?

A live stream has no end, so the download would never finish. Download it after it ends and the recording is published.

What does the app send to the internet?

Only what's needed: the link you download goes to that website, and update checks go to GitHub and PyPI. SponsorBlock is asked only if you turn it on, and then only with 4 characters of an encoded video ID. No accounts, statistics or tracking.

How is it different from download websites?

Download websites run everything on their server: your link and IP address go to them and to ad networks, and they pay for it with pop-ups, fake buttons and often a lower quality. Video Download works on your own computer or phone, without ads or accounts, in full quality, and your links go to no one but the site you download from.

Is it safe?

The code is public on GitHub, every installer has a SHA-256 checksum, and the app installs only updates digitally signed by us, on Windows, Mac, Linux and Android.
