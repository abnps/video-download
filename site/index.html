Features

Everything you need,
nothing you don't.

A simple window, with everything you expect from a good downloader underneath.

MP4 up to the best quality

Best, 1080p, 720p or 480p. Picture and sound are merged into an MP4 (H.264/AAC when the site offers it) that plays on most devices.

Audio only: MP3 or M4A

For lectures, podcasts and music. A finished MP4 turns into an MP3 with one button.

Copy a link, done

The app notices a copied link and adds it to the queue.

Playlists, several at once

Whole playlists, up to 4 downloads at the same time, automatic retry when the connection drops.

Clips, subtitles, cover art

Just a part of a video, subtitles in the MP4 and the thumbnail as the file's cover.

Light and dark theme

Or same as your system. Progress on the taskbar and a notification at the end.

Always up to date, and safe

The app checks for new versions itself, updates the part that reads websites without reinstalling. On Windows it installs only updates digitally signed by us; on Mac (beta) new versions are downloaded by hand for now.

Download for Windows

Beta New: Video Download for Mac. For Macs with an Apple chip (M1 or newer) and macOS 13 or later. It works, but only a few people have tried it so far: please report anything that doesn't work.

The Mac version isn't signed by Apple yet, so the first start takes a few extra clicks:

  1. Open the downloaded .dmg and drag Video Download to Applications.
  2. Open the app. macOS says it can't verify it: click Done (not “Move to Trash”).
  3. Open System Settings → Privacy & Security, scroll down, click Open Anyway and enter your Mac password.
  4. Open the app again and confirm Open. This is needed only once.

Download for Mac (beta)

Beta New: Video Download for Android. For phones with Android 10 or later. Share a video from any app and pick the quality. It works, but only a few people have tried it so far: please report anything that doesn't work.

The app isn't in Google Play, so the first install takes a few extra taps:

  1. Open the downloaded file (Downloads or the browser's download list).
  2. If Android asks, allow installing apps from your browser: Settings → Allow from this source.
  3. On Samsung phones, turn off Auto Blocker for the install (Settings → Security and privacy).
  4. If Google Play Protect warns about an unknown app, tap More details → Install anyway.
  5. Later versions install from the app itself: Settings → Check for updates.

What's new

Better every week.

The same list as in the app (Help → What's new).

0.9.7 27.9.2026

  • Clear error messages in the app's language (e.g. “The video is no longer available”, “Can't reach the site”); the technical message stays in the tooltip and in the problem report.
  • Two downloads never write the same file: not the same video through two links, not long titles that start the same, not clips within the same second; an MP3 of the same video no longer deletes the MP4 you already have.
  • The queue saves itself after every change, so a crash or power cut doesn't lose links; “Download all” while a link is still being read starts as soon as the link arrives.
  • “Stop” also stops MP3 conversion, while “Remove all from list” and “Clear finished” keep an MP3 that is still being made; closing the app no longer starts new downloads.
  • A retry after a dropped connection really waits 5 seconds; the problem report hides passwords and keys more thoroughly.
  • The browser extension opens a welcome page when installed (checks the connection to the app, shows how to pin the icon); a bigger × button and a nicer picture while the thumbnail loads.

0.9.6 26.9.2026

  • Updates are digitally signed: the app installs only a new version signed by us, even if someone swaps the file where it is published.
  • On first start, a short notice that the app watches copied links, with a button to turn it off right away.
  • Leftover temporary cookie files (after a sudden shutdown) are removed on the next start; long lists use less memory.
  • The connection with the browser add-on copes better with slow or stuck requests.

0.9.5 26.9.2026

  • 1080p, 720p and 480p get a tag in the file name, so a different quality of the same video is no longer “already downloaded”.
  • Two videos with the same title (file name without ID) no longer get mixed up; the same video started twice at once waits for the first one.
  • “Finished” only when the file exists and can be read; MP3 conversion can always be stopped.
  • Closing the app no longer freezes the window; updating also waits for MP3 conversions.

Help

Questions?

If something doesn't work: in the app use Help → Save a problem report, then report the problem. Reports are public: don't include passwords or personal data.

A video suddenly won't download.

Websites change often. Help → Update the site reader (yt-dlp), then try again.

Why aren't live streams downloaded?

A live stream has no end, so the download would never finish. Download it after it ends and the recording is published.

What does the app send to the internet?

Only what's needed: the link you download goes to that website, and update checks go to GitHub and PyPI. No accounts, statistics or tracking.

Is it safe?

The code is public on GitHub, every installer has a SHA-256 checksum, and the app installs only updates digitally signed by us on Windows (on Mac, beta, you download new versions by hand for now).
