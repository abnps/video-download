Browser-Erweiterung

Firefox

Installation in Firefox – ohne Entwicklermodus. Die Erweiterung ist von Mozilla signiert und aktualisiert sich selbst.

Zu Firefox hinzufügen

  1. Installiere zuerst die App (die Erweiterung arbeitet mit ihr).
  2. Klicke in Firefox 140 oder neuer unten auf Zu Firefox hinzufügen: die offizielle Seite von Firefox Add-ons öffnet sich.
  3. Klicke dort auf Zu Firefox hinzufügen und dann auf Hinzufügen.
  4. Hefte das Symbol von Video Download an (Puzzle-Symbol → Anheften).

Microsoft Edge

Installation in Edge aus dem offiziellen Store Edge-Add-ons – ohne Entwicklermodus. Die Erweiterung aktualisiert sich selbst.

Für Edge herunterladen

  1. Installiere zuerst die App (die Erweiterung arbeitet mit ihr).
  2. Klicke unten auf Für Edge herunterladen: die offizielle Seite von Edge-Add-ons öffnet sich.
  3. Klicke auf der Seite von Edge-Add-ons auf Abrufen und dann auf Erweiterung hinzufügen.
  4. Hefte das Symbol von Video Download an (Puzzle-Symbol → Augen-Symbol).

Chrome: manuell, in 3 Schritten

Installiere zuerst die App (die Erweiterung ist dabei). Für Chrome gibt es keine Store-Version, daher wird sie einmal aus dem App-Ordner geladen:

Ordnerpfad kopieren Erweiterungen in Chrome öffnen
→
chrome://extensions

Entpackte Erweiterung laden Erweiterung packen

Ordner auswählen

Ordner auswählen
  1. Öffne in der App Hilfe → Aus dem Browser herunterladen und klicke auf Ordnerpfad kopieren.
  2. Klicke auf Erweiterungen in Chrome öffnen (oder öffne chrome://extensions) und schalte den Entwicklermodus ein (oben rechts).
  3. Klicke auf Entpackte Erweiterung laden, füge den Pfad (Strg+V) in das Ordnerfeld ein und klicke auf Ordner auswählen. Hefte dann das Symbol von Video Download an (Puzzle-Symbol → Anheften).
Chrome erinnert eventuell an den „Entwicklermodus“; das ist normal. Reagiert die Erweiterung nach einem App-Update nicht mehr, klicke in chrome://extensions bei ihr auf Neu laden. Firefox und Edge aktualisieren die Erweiterung selbst.

Verwendung

  • Spiele ein Video ab und klicke auf das Symbol von Video Download: Laufendes Video herunterladen oder Als MP3 herunterladen.
  • Rechtsklick auf einen Link oder ein Video: Diesen Link herunterladen oder …als MP3.
  • Läuft die App nicht, startet der Klick sie.
  • Livestreams und DRM-geschützte Videos werden nicht heruntergeladen.
Mac (Beta): Der Ordner liegt im Programm. In der App Hilfe → Aus dem Browser herunterladen → Ordnerpfad kopieren, dann im Ordnerdialog ⌘⇧G drücken, einfügen (⌘V) und Return drücken.
