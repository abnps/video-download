Descargar una lista de reproducción completa

Pega el enlace de una lista y todos sus vídeos pasan a la cola. Video Download descarga varios a la vez y lo vuelve a intentar solo si se corta la conexión.

Pasos

  1. Copia el enlace de la lista y pulsa Pegar. Se añaden todos sus vídeos.
  2. Elige el formato, por ejemplo Vídeo – mejor calidad (MP4) o Solo audio – MP3. Se aplica a todo lo que espera en la lista; una fila puede tener su propio formato con su botón de formato.
  3. Pulsa Descargar.

Conviene saber

  • El enlace de un solo vídeo que forma parte de una lista descarga solo ese vídeo. Para la lista completa, activa Descargas → Enlace de vídeo de una lista: descargar la lista completa.
  • Descargas → Descargas simultáneas: de 1 a 4 descargas a la vez.
  • Si se corta la conexión, la descarga se reintenta hasta 3 veces.

Video Download es gratis para Windows y Mac.
