Privacidad

Ni el sitio web ni la aplicación recogen datos sobre ti.

Este sitio web

  • El sitio web no tiene cookies, analítica, anuncios ni formularios, y no guarda nada en tu navegador.
  • El sitio web está alojado en GitHub Pages (GitHub, Inc.). Como cualquier servidor, GitHub registra datos técnicos como tu dirección IP por seguridad y funcionamiento; consulta la declaración de privacidad de GitHub.
  • El instalador se descarga de GitHub (mismas condiciones que arriba).
  • El botón de apoyo lleva a PayPal; PayPal solo recibe datos cuando lo abres, según sus propias normas.
  • Los informes de problemas van a GitHub Issues y son públicos (hace falta una cuenta de GitHub). El informe de la aplicación acorta los enlaces al nombre del sitio y oculta tu nombre de usuario de Windows; no añadas contraseñas, cookies ni datos personales.
  • Las contribuciones las procesa PayPal. Como destinatario, el autor ve lo que PayPal muestra de cada pago (p. ej., el nombre y el correo de quien paga) y lo usa solo para la contabilidad, nunca para publicidad ni nada más.
  • Los mensajes a abnpsdev@gmail.com (la dirección de contacto del proyecto, un buzón de Gmail en Google) se usan solo para responderte y nunca se comparten ni se usan para nada más.

La aplicación

En resumen: el autor del programa no recopila ningún dato sobre ti. Sin cuentas, sin seguimiento, sin anuncios.

1. Lo que el programa no hace

El programa no envía al autor ningún dato, estadística de uso ni informe de errores. No hay anuncios ni analítica.

2. Con quién se conecta el programa

  • Con el sitio desde el que descargas (vídeo, audio, miniaturas, subtítulos).
  • Con GitHub (api.github.com, github.com): comprobar y descargar una nueva versión del programa, como máximo una vez al día y cuando pulsas «Buscar actualizaciones».
  • Con PyPI (pypi.org, files.pythonhosted.org): comprobar y descargar el lector de sitios yt-dlp, como máximo una vez al día.
  • Con PayPal solo si pulsas «Apoyar el proyecto»: la página de aportaciones de PayPal se abre en tu navegador y el programa no envía nada.

Estos servicios ven tu dirección IP y la versión del programa; se aplican sus propias políticas de privacidad.

3. Qué se guarda en tu ordenador

La configuración (registro: HKCU\Software\VideoDownload), la cola y el historial de descargas (enlaces, títulos, rutas, tamaños, horas) y el yt-dlp descargado en la carpeta %LOCALAPPDATA%\VideoDownload, además de una clave local para la conexión con el navegador. Nada de ello sale de tu ordenador.

4. Cookies de inicio de sesión

Solo si lo permites en el navegador. Al programa solo llegan las cookies del sitio desde el que descargas; se guardan solo en memoria y el archivo temporal para yt-dlp se borra de inmediato. Nunca se escriben en la cola, el historial ni los informes.

5. Extensión del navegador

Permisos: observar las solicitudes de red (para reconocer flujos de vídeo), un script en la página (para encontrar el vídeo en reproducción y reconocer DRM), el menú contextual, una conexión local con el programa (native messaging) y almacenamiento temporal por pestaña; cookies solo si las permites. La extensión no envía nada a internet: solo pasa datos al programa de tu ordenador, y solo cuando haces clic.

6. Informe del problema

Solo se crea cuando tú lo guardas. Los enlaces aparecen acortados al nombre del sitio, y el nombre de usuario y los secretos están ocultos. Solo lo envías si tú lo decides.

7. Borrar los datos

El historial se borra en Descargas → Historial de descargas → Borrar la lista. La desinstalación elimina el programa, la conexión con el navegador y el yt-dlp descargado. La cola, el historial y la configuración permanecen hasta que borres la carpeta %LOCALAPPDATA%\VideoDownload y la clave HKCU\Software\VideoDownload.

8. Contacto

Como el autor no recopila datos, no hay datos que pueda facilitar, corregir o borrar. Preguntas: https://github.com/abnps/video-download/issues
